# Head and Tail

## `head`

```bash
head filename
```

By default, `head` displays the **top 10 lines** of a file.

### Example

```bash
head file.txt
```

Shows:

```text
Line 1
Line 2
...
Line 10
```

### View a Specific Number of Lines

```bash
head -20 filename
```

This displays the **first 20 lines**.

---

## `tail`

```bash
tail filename
```

By default, `tail` displays the **bottom 10 lines** of a file.

### Example

```bash
tail file.txt
```

Shows the last 10 lines.

### View a Specific Number of Lines

```bash
tail -20 filename
```

This displays the **last 20 lines**.

---

# `head` vs `tail`

```text
head
↓
Reads from the top of the file.

tail
↓
Reads from the bottom/end of the file.
```

---

## View Continuous New Lines

```bash
tail -f filename
```

This continuously displays **new lines added to the file**.

### Example

```bash
tail -f /var/log/syslog
```

If new log entries are added, they will automatically appear on your screen.

This is commonly used for **monitoring log files**.

---

# View a Specific Line

```bash
cat -n filename | head -5 | tail -1
```

### How It Works

```text
cat -n filename
        ↓
Adds line numbers to every line.

head -5
        ↓
Keeps only the first 5 lines.

tail -1
        ↓
Shows the last line from those 5 lines.
```

Therefore:

```bash
cat -n filename | head -5 | tail -1
```

Displays the **5th line**.

### General Syntax

To display the **Nth line**:

```bash
cat -n filename | head -n N | tail -n 1
```

### Example: Display the 10th Line

```bash
cat -n filename | head -n 10 | tail -n 1
```

---

# `nl` — View Lines With Numbers

```bash
nl filename
```

This displays the contents of a file along with **line numbers**.

### Example

```text
     1  Apple
     2  Mango
     3  Orange
```

---

# `tac` — Reverse `cat`

```bash
tac filename
```

`tac` displays the file **from bottom to top**.

### Example File

```text
Line 1
Line 2
Line 3
```

Running:

```bash
tac filename
```

Output:

```text
Line 3
Line 2
Line 1
```

## Simple Understanding

```text
cat
↓
Top to bottom

tac
↓
Bottom to top
```
