# 📁 Important Linux Directories

---

## `/` — Root Directory

* In Windows, the top level is a drive such as:

```text
C:\
```

* In Linux, the top level is:

```text
/
```

➡️ All directories and files are under `/`.

### Example:

```text
/
├── bin
├── boot
├── dev
├── etc
├── mnt
├── opt
├── proc
├── tmp
└── var
```

➡️ `/` is the **starting point of the entire Linux filesystem**.

---

# `/bin` — Essential Commands

* All essential commands will be in `/bin`.

### Examples:

```text
ls
touch
cp
cat
```

### What these commands do:

| Command | Purpose |
|---|---|
| `ls` | Lists files and directories |
| `touch` | Creates an empty file |
| `cp` | Copies files or directories |
| `cat` | Displays the contents of a file |

* `/bin` commands can generally be used by normal users.

### `/sbin`
* `/sbin` Superbin commands can only be used by root
* `/sbin` means **System Binary**.
* It contains commands mainly used for system administration and maintenance.

➡️ Some `/sbin` commands may require **root/superuser privileges**.

### Simple Difference:

```text
/bin
 ↓
Essential commands used by users


/sbin
 ↓
System administration commands
```

> **NOTE:** On many modern Linux distributions, `/bin` and `/sbin` may be linked or merged with `/usr/bin` and `/usr/sbin`.

---

# `/boot` — Boot Files

* All boot files will be stored here.

### Example:

Linux starting and booting files.

When you start your computer:

```text
Power ON
    ↓
Bootloader Starts
    ↓
Linux Kernel Loads
    ↓
Linux Operating System Starts
```

➡️ `/boot` contains important files required during this startup process.

### It can contain:

- Linux Kernel
- Bootloader files
- `initramfs`

---

# `/etc` — Configuration Files

* All Linux installed configuration-related files are stored in `/etc`.

### Examples:

```text
/etc/hosts
/etc/passwd
/etc/ssh/
```

➡️ `/etc` mainly contains **system-wide configuration and settings files**.

### Simple Example:

Suppose you install and configure an SSH server.

Its configuration files can be found inside:

```text
/etc/ssh/
```

Think of `/etc` as:

```text
/etc
 ↓
Configuration
Settings
System-related setup
```

> ⚠️ `C:\Program Files` is not an exact equivalent of `/etc`.  
> `C:\Program Files` stores installed application files, while `/etc` mainly stores configuration files.

---

# `/opt` — Third-Party Software

* Third-party or optional software can be stored here.

### Example:

```text
/opt/application-name/
```

Suppose you manually install an application called `myapp`.

It may be installed like:

```text
/opt/myapp/
```

➡️ `/opt` is commonly used for **additional or optional application software**.

---

# `/dev` — Device Files

* Device files will be available here.

### Examples:

```text
Hard Disk
Keyboard
Mouse
Terminal
```

Linux represents many devices using special files inside:

```text
/dev
```

### Examples:

```text
/dev/sda
/dev/tty
/dev/null
```

For example:

```text
/dev/sda
```

can represent a storage disk.

➡️ `/dev` allows Linux and programs to interact with devices.

---

# `/var` — Variable Files

* Variable files such as:

```text
Logs
Cache
```

are stored under `/var`.

### Examples:

```text
/var/log
/var/cache
```

### `/var/log`

Contains system and application logs.

Example:

```text
Server started
User logged in
Application error
```

### `/var/cache`

Contains cached data created by applications.

➡️ `/var` mainly stores data that **changes frequently** while the system is running.

```text
/var
 ↓
Changing Data
 ↓
Logs + Cache + Other Application Data
```

---

# `/proc` — Process and System Information

* Contains information about current running processes and the system.

`/proc` is a special **virtual filesystem**.

It provides information about:

- Running Processes
- CPU
- Memory
- Kernel
- System Information

### Examples:

```text
/proc/cpuinfo
/proc/meminfo
```

You can check:

```bash
cat /proc/cpuinfo
```

➡️ Displays information about the CPU.

You can also check:

```bash
cat /proc/meminfo
```

➡️ Displays memory information.

### Simple Understanding:

```text
/proc
 ↓
Live System Information
 ↓
Processes + CPU + Memory + Kernel
```

---

# `/mnt` — Mount Point

* `/mnt` is used as a mount point.

### Examples:

```text
External Hard Drive
USB
CD/DVD
```

### What does Mount mean?

When you connect a storage device, Linux needs to make its filesystem accessible through a directory.

Example:

```text
External Hard Drive
        ↓
      Mount
        ↓
       /mnt
```

After mounting, you can access the files through a directory such as:

```text
/mnt/usb
```

### Example Command:

```bash
mount /dev/sdb1 /mnt
```

➡️ This mounts the filesystem from `/dev/sdb1` to `/mnt`.

---

# `/tmp` — Temporary Files

* Temporary files will be stored here.

```text
/tmp
```

Applications and users can create temporary files inside this directory.

### Example:

```text
/tmp/tempfile.txt
```

➡️ These files are not usually intended for permanent storage.

* The system may delete temporary files after some time, depending on the Linux distribution and configuration.

---

# ⭐ Easy Way to Remember

```text
/       → Root of the Linux filesystem

/bin    → Essential commands
/sbin   → System administration commands

/boot   → Files required to start Linux

/etc    → Configuration and settings files

/opt    → Optional / third-party software

/dev    → Device files and interfaces

/var    → Changing data
           Logs
           Cache

/proc   → Process and live system information

/mnt    → Mount point for storage devices

/tmp    → Temporary files
```
