# Find Command

## What is `find`?

* `find` command is used to **search and locate files and directories based on conditions**.

---

## Find a File or Directory

* Find a file or directory in the whole server:

```bash
find / -name fileordirname
```

### Example:

```bash
find / -name test.txt
```

```text
find  = command
/     = path (search from root / whole server)
-name = condition
test.txt = file or directory name
```

---

## Find a File

```bash
find / -name filename -type f
```

### Example:

```bash
find / -name test.txt -type f
```

```text
-type = type condition
f     = file
```

➡️ It searches only for files.

---

## Find a Directory

```bash
find / -name dirname -type d
```

### Example:

```bash
find / -name Documents -type d
```

```text
-type = type condition
d     = directory
```

➡️ It searches only for directories.

---

## `.` = Current Location

```text
. = Current location
```

### Find a file or directory in the current location:

```bash
find . -name filename
```

### Example:

```bash
find . -name test.txt
```

➡️ It searches from the current directory and its subdirectories.

---

# Find Files with Extension

## Find files with `.exe` extension

```bash
find / -name "*.exe" -type f
```

### Example:

```text
file.exe
test.exe
hello.exe
```

```text
* = anything / any characters
.exe = extension
```

➡️ `*.exe` means any file name ending with `.exe`.

---

# Lowercase and Uppercase

## `-name`

```bash
find / -name "*.exe" -type f
```

➡️ `-name` is **case-sensitive**.

For example:

```text
test.exe
TEST.EXE
```

These are treated differently.

---

## `-iname`

```bash
find / -iname "*.exe" -type f
```

➡️ `-iname` means **ignore case**.

It can find:

```text
test.exe
TEST.EXE
Test.Exe
tEsT.eXe
```

---

# Find Empty Files

## Find empty files in the server

```bash
find / -type f -empty
```

```text
-type f = file
-empty  = empty
```

➡️ It finds files that contain no data.

---

## Find Empty Files in a Directory

```bash
find /dirname -type f -empty
```

### Example:

```bash
find /home/user -type f -empty
```

➡️ It searches for empty files inside `/home/user`.

---

# Find Empty Directory

```bash
find /dirname -type d -empty
```

### Example:

```bash
find /home/user -type d -empty
```

```text
-type d = directory
-empty  = empty
```

➡️ It finds directories that contain no files or subdirectories.

---

# Conditions in `find`

Conditions like:

```text
-type
-perm
-date / time
-size
```

are used to search files and directories based on different requirements.

---

# Search by Permission

## Find which directory has Full Permissions

```bash
find / -type d -perm 777
```

### `777` means:

```text
Owner = rwx = 4 + 2 + 1 = 7
Group = rwx = 4 + 2 + 1 = 7
Other = rwx = 4 + 2 + 1 = 7

777
```

➡️ `777` means the owner, group, and others have read, write, and execute permissions.

---

## Find which directory does NOT have Full Permissions

```bash
find / -type d ! -perm 777
```

```text
! = NOT
```

➡️ It finds directories whose permission is not exactly `777`.

---

# Search by Size

## Find More Than 100 MB Files

```bash
find / -size +100M
```

```text
+100M = More than 100 MB
```

➡️ It finds files larger than 100 MB.

---

## Find Files from 10 MB to 100 MB

```bash
find / -size +10M -size -100M
```

```text
+10M  = More than 10 MB
-100M = Less than 100 MB
```

➡️ It finds files between these size conditions.

---

# Time and Date

## Find Files by Date

```bash
find /dirname -mtime -7
```

```text
-mtime = Modification time
-7     = Within the last 7 days
```

➡️ It finds files modified within the last 7 days.

---

## Find Files Within 30 Minutes

```bash
find /dirname -mmin -30
```

```text
-mmin = Modification time in minutes
-30   = Within the last 30 minutes
```

➡️ It finds files modified within the last 30 minutes.

---

# Delete Files with the Same Name in Different Directories

```bash
find / -name filename -type f -print -exec rm -f {} \;
```

### Example:

Suppose the same file exists in different directories:

```text
/home/user/test.txt
/var/test.txt
/opt/test.txt
```

The command:

```bash
find / -name test.txt -type f -print -exec rm -f {} \;
```

➡️ Searches for `test.txt` from `/`.

➡️ `-type f` makes sure it is a file.

➡️ `-print` shows the file before deleting it.

➡️ `-exec` executes another command on every matching file.

➡️ `rm -f` removes the file.

➡️ `{}` represents the file found by `find`.

➡️ `\;` indicates the end of the `-exec` command.

### `-print`

```text
-print = Shows in which directory the file was deleted/found.
```

### IMPORTANT

First check which files will be matched:

```bash
find / -name test.txt -type f -print
```

After checking the output, use:

```bash
find / -name test.txt -type f -print -exec rm -f {} \;
```

# Quick Revision

```bash
# Find a file or directory
find / -name filename

# Find a file
find / -name filename -type f

# Find a directory
find / -name dirname -type d

# Find in current location
find . -name filename

# Find .exe files
find / -name "*.exe" -type f

# Find extension ignoring uppercase/lowercase
find / -iname "*.exe" -type f

# Find empty files
find / -type f -empty

# Find empty files in a directory
find /dirname -type f -empty

# Find empty directories
find /dirname -type d -empty

# Find directories with full 777 permissions
find / -type d -perm 777

# Find directories without exact 777 permissions
find / -type d ! -perm 777

# Find files more than 100 MB
find / -size +100M

# Find files between 10 MB and 100 MB
find / -size +10M -size -100M

# Find files modified within 7 days
find /dirname -mtime -7

# Find files modified within 30 minutes
find /dirname -mmin -30

# Display matching files
find / -name filename -type f -print

# Delete matching files
find / -name filename -type f -print -exec rm -f {} \;
```
