# VI / VIM — Visual Editor

> **EL5 idea:**  
> Vim is a text editor, but unlike Notepad or VS Code, the keyboard behaves differently depending on the **mode** you are in.
>
> Think of Vim like having different "jobs":
>
> - **Normal Mode** → move around and perform editing commands.
> - **Insert Mode** → actually type text.
> - **Command-line Mode** → give Vim commands such as save, quit, replace, and show line numbers.

---

# 1. What is VI / VIM?

## VI

**vi** is a terminal-based text editor.

## VIM

**Vim** means **Vi IMproved**.

It is an improved/extended version of the traditional `vi`.

So:

```text
vi  → original editor
Vim → improved version of vi
```

They are **not literally the same program**, although Vim is designed to be highly compatible with vi.

---

# 2. Vim Modes

The basic modes discussed here are:

```text
1. Normal Mode
2. Insert Mode
3. Command-line Mode
```

Vim also has other modes/features, such as Visual Mode and Replace Mode, but these three are the main modes covered in these notes.

---

## 2.1 Normal Mode

### What is it?

Normal Mode is the default mode used for **commands and navigation**.

When Vim starts, you normally begin in Normal Mode.

In Normal Mode, pressing keys such as:

```text
h
j
k
l
d
y
p
u
g
G
0
$
```

does not normally insert those letters into the file.

Instead, they perform commands.

### EL5 example

Imagine your file contains:

```text
Hello
World
Linux
Vim
```

If you press:

```text
j
```

you move down.

If you press:

```text
dd
```

you delete a line.

If you press:

```text
yy
```

you copy/yank a line.

So:

> **Normal Mode = "Do something to the text."**

---

# 3. Insert Mode

Insert Mode is the mode in which you **type/add text**.

To enter Insert Mode from Normal Mode:

```text
i
```

After pressing `i`, you can type normally.

Example:

```text
i
Hello Ravi
```

The text `Hello Ravi` is inserted into the file.

To leave Insert Mode:

```text
Esc
```

This returns you to Normal Mode.

The official Vim documentation confirms that `i` starts Insert Mode and `Esc` returns to Normal Mode. :contentReference[oaicite:4]{index=4}

### Important distinction

Insert Mode is primarily for **inserting/typing text**.

It is not correct to say that Insert Mode itself is the mode for all "adding, removing, and replacing."

For example:

- Type text → Insert Mode
- Delete a line → normally Normal Mode using `dd`
- Replace text → can be done using Normal Mode commands or Replace Mode
- Delete characters while typing → Backspace/Delete in Insert Mode

---

# 4. Command-line Mode / Colon Mode

Command-line Mode is entered from Normal Mode by pressing:

```text
:
```

You will see a colon at the bottom of the screen.

Example:

```text
:w
```

Then press:

```text
Enter
```

Vim executes the command.

Command-line Mode is used for Ex commands such as:

```text
:w
:q
:wq
:q!
:set number
:%s/old/new/g
```

The official Vim documentation describes Command-line Mode as the mode used for Ex commands beginning with `:`, as well as search patterns and filter commands. :contentReference[oaicite:5]{index=5}

### EL5 idea

Think of:

```text
Normal Mode  → keyboard shortcuts
Insert Mode  → typing
Command-line Mode → giving Vim instructions
```

# 6. Entering Insert Mode

Suppose you opened:

```bash
vi notes.txt
```

You are initially in Normal Mode.

Press:

```text
i
```

Now you are in Insert Mode.

You can type:

```text
Hello World
```

When finished typing:

```text
Esc
```

Now you are back in Normal Mode.

# 7. Saving a File

Before using a command such as `:w`, you should be in Normal Mode.

If you are currently in Insert Mode:

```text
Esc
```

Then press:

```text
:
```

and type:

```text
w
```

So the complete command is:

```vim
:w
```

Then press:

```text
Enter
```

### Meaning

```text
:w
```

means:

> **Write/save the current file.**

---

# 8. Save and Exit

Use:

```vim
:wq
```

Then press:

```text
Enter
```

Meaning:

```text
:w  → write/save
:q  → quit
```

Therefore:

```text
:wq
```

means:

> **Save the file and exit Vim.**

---

# 9. Quit Without Saving

Use:

```vim
:q!
```

Then press:

```text
Enter
```

Meaning:

```text
:q  → quit
!   → force the command
```

Therefore:

```text
:q!
```

means:

> **Quit Vim without saving the changes.**

This is useful when you changed something accidentally and do not want to keep the changes.

---

# 10. Force Save

You may also see:

```vim
:w!
```

The `!` means to force the operation when Vim allows/needs a forced write.

Do not confuse:

```vim
:q!
```

with:

```vim
:w!
```

They do different things.

```text
:q!  → force quit without saving
:w!  → force write/save
```

---

# 11. Quit Without Saving — Short Form

Vim also has:

```text
ZQ
```

in Normal Mode.

It quits without saving.

Another useful Normal Mode command is:

```text
ZZ
```

which saves and exits.

For beginners, however, the explicit commands are easier to remember:

```vim
:wq
:q!
```

# 12. Moving the Cursor in Vim

Cursor movement is mainly performed in Normal Mode.

You can use the arrow keys:

```text
↑
↓
←
→
```

You can also use Vim's traditional movement keys:

```text
k = Up
j = Down
h = Left
l = Right
```

So:

```text
        k
        ↑
    h ←   → l
        ↓
        j
```

### Easy way to remember

```text
h → left
j → down
k → up
l → right
```

The arrows are also usable, but learning `h j k l` is important because they are fundamental Vim movement keys.

# 13. Go to the Last Line

In Normal Mode:

```text
G
```

moves the cursor to the **last line** of the file.

Example:

```text
1   Hello
2   Linux
3   Vim
4   World
```

If the cursor is on line 1 and you press:

```text
G
```

the cursor goes to:

```text
4   World
```

---

# 14. Go to the First Line

In Normal Mode:

```text
gg
```

moves the cursor to the **first line**.

Example:

```text
1   Hello
2   Linux
3   Vim
4   World
```

Press:

```text
gg
```

and the cursor goes to line:

```text
1
```

# 15. Go to the Beginning of the Current Line

Use:

```text
0
```

This moves the cursor to the beginning of the current line.

Example:

```text
Hello Linux World
     ^
```

Press:

```text
0
```

The cursor moves to:

```text
^Hello Linux World
```

---

# 16. Go to the End of the Current Line

Use:

```text
$
```

This moves the cursor to the end of the current line.

Example:

```text
Hello Linux World
^
```

After:

```text
$
```

the cursor goes to the end:

```text
Hello Linux World$
```

The `$` command means the end of the line in Normal Mode.

# 17. Go Directly to a Particular Line

You can give Vim a line number.

For example:

```text
:7
```

followed by `Enter` moves to line 7.

A very useful method when opening a file is:

```bash
vi +7 filename
```

This opens the file and places the cursor on **line 7**.

Example:

```bash
vi +25 notes.txt
```

This opens `notes.txt` with the cursor positioned on line 25.

So:

```text
vi +7 filename
```

means:

```text
Open filename
      +
Start at line 7
```

---

# 18. Important Correction About the Note

The handwritten note says:

```text
While entering the vi mode the cursor should be in particular number.
(vi filename ++7)
```

The correct syntax is:

```bash
vi +7 filename
```

NOT:

```bash
vi filename ++7
```

For example:

```bash
vi +7 notes.txt
```

The `+7` tells Vim to start at line 7.

# 19. Delete the Current Line

In Normal Mode:

```text
dd
```

deletes the current line.

Example:

```text
Hello
Linux
Vim
World
```

If the cursor is on:

```text
Linux
```

press:

```text
dd
```

Result:

```text

Vim
World
```

# 20. Delete Multiple Lines

You can put a number before `dd`.

Example:

```text
6dd
```

means:

> Delete 6 lines starting from the current line.

Examples:

```text
2dd  → delete 2 lines
4dd  → delete 4 lines
6dd  → delete 6 lines
10dd → delete 10 lines
```

The number is called a **count**.

General pattern:

```text
[count]dd
```

Use:

```text

```

in Normal Mode.

It deletes the character under the cursor.

Example:

```text

  ^
```

Press:

```text
x
```

and the character under the cursor is deleted.

You can also use a count:

```text
5x
```

to delete 5 characters starting at the cursor.

In Vim, "copy" is usually called **yank**.

Use:

```text

```

to yank/copy the current line.

Example:

```text

Vim
```

If the cursor is on:

```text

```

press:

```text

```

The line is copied into Vim's register.

# 23. Paste

After copying with:

```text
yy
```

use:

```text
p
```

to paste.

Example:

```text
Hello
Linux
Vim
```

Suppose you are on `Linux`:

```text

```

pastes them.

Example:


You accidentally delete something.

Press:


and Vim undoes the change.

# 26. Search and Replace

One of the most important Vim commands is:

```vim
:s/oldword/newword/g
```

Let's break it down.

```text
:
```

Enter Command-line Mode.

```text
s
```

means:

```text
substitute
```

Then:

```text
/oldword/
```

is the text you want to find.

Then:

```text
/newword/
```

is the replacement text.

Finally:

```text
g
```

means replace all matching occurrences on that line.

So:

```vim
:s/oldword/newword/g
```

means:

> Search for `oldword` on the current line and replace all occurrences with `newword`.

---

# 27. Understand the `g`

This is very important.

By default:

```vim
:s/old/new/
```

changes only the **first matching occurrence on the current line**.

Adding:

```text
g
```

makes it replace **all matching occurrences on that line**.

Therefore:

```vim
:s/old/new/
```

means:

```text
Replace first match on current line
```

while:

```vim
:s/old/new/g
```

means:

```text
Replace every match on current line
```

The official Vim documentation confirms that `:s` normally changes only the first occurrence on a line, while `g` changes every occurrence on that line. :contentReference[oaicite:6]{index=6}

---

# 28. Replace a Word on All Lines in a File

To replace every occurrence throughout the entire file:

```vim
:%s/old/new/g
```

Example:

```vim
:%s/oldword/newword/g
```

Breakdown:

```text
:       → Command-line Mode
%       → all lines in the file
s       → substitute
oldword → search text
newword → replacement text
g       → every occurrence on each selected line
```

Therefore:

```vim
:%s/oldword/newword/g
```

means:

> Replace every occurrence of `oldword` with `newword` throughout the entire file.

The `%` is the range representing all lines. :contentReference[oaicite:7]{index=7}

---

# 29. Replace Only Lines 1 to 7

To replace text only between line 1 and line 7:

```vim
:1,7s/old/new/g
```

Example:

```vim
:1,7s/oldword/newword/g
```

Breakdown:

```text
1,7     → lines 1 through 7
s       → substitute
oldword → text to find
newword → replacement
g       → replace every occurrence on each selected line
```

So:

```vim
:1,7s/oldword/newword/g
```

means:

> Replace every occurrence of `oldword` with `newword`, but only on lines 1 through 7.

---

# 30. Replace Throughout the Whole File vs Selected Lines

## Whole file

```vim
:%s/old/new/g
```

Meaning:

```text
All lines
```

## Only lines 1–7

```vim
:1,7s/old/new/g
```

Meaning:

```text
Only lines 1 through 7
```

This is the important difference:

```text
%       → entire file
1,7     → lines 1 through 7
```

# 31. Set Line Numbers

To display line numbers:

```vim
:set number
```

or:

```vim
:set nu
```

Example:

```text
1  Hello
2  Linux
3  Vim
4  World
```

Now you can easily see which line you are working on.

### Why is this useful?

Suppose you want to edit line 7.

With line numbers enabled:

```text
1
2
3
4
5
6
7  <-- target line
8
9
```

You can clearly see the line number.

---

# 32. The Difference Between `:set number` and `:set nu`

Both work:

```vim
:set number
```

and:

```vim
:set nu
```

`number` is the full option name.

`nu` is its abbreviation.

For learning, it is better to remember:

```vim
:set number
```

because it is easier to understand.

# 33. A Complete Example

Suppose we have:

```text
Hello Linux
Hello Linux
Hello Vim
Linux is powerful
Linux is fast
Linux is free
Linux is popular
Another Linux line
```

We want to replace `Linux` with `Unix` only from line 1 to line 7.

First open the file:

```bash
vi notes.txt
```

If necessary, show line numbers:

```vim
:set number
```

Then execute:

```vim
:1,7s/Linux/Unix/g
```

Result:

```text
1  Hello Unix
2  Hello Unix
3  Hello Vim
4  Unix is powerful
5  Unix is fast
6  Unix is free
7  Unix is popular
8  Another Linux line
```

Notice line 8 still contains `Linux`.

Why?

Because we specified:

```text
1,7
```

So only lines 1 through 7 were affected.

```text

   ↓

   ↓

   ↓
Insert Mode
   ↓
Type/edit text
   ↓
Press Esc
   ↓
Normal Mode
   ↓
Press :
   ↓
Command-line Mode
   ↓
:w
   ↓
Save
```

For save and exit:

```text
Esc
:wq
Enter
```

For exit without saving:

```text
Esc
:q!
Enter
```

# 40. The Core Idea

If you remember only one thing from this chapter, remember:

```text
Esc
 ↓
NORMAL MODE
 ↓
 ├── i  → type text
 ├── h/j/k/l → move
 ├── dd → delete
 ├── yy → copy
 ├── p → paste
 ├── u → undo
 └── : → command-line mode
              ↓
              ├── :w → save
              ├── :wq → save + exit
              ├── :q! → exit without saving
              ├── :set number → line numbers
              └── :%s/old/new/g → replace
```

> **The single most important Vim habit:**
>
> ```text
> When in doubt → Esc → Normal Mode
> ```
>
> From Normal Mode, you can decide whether you want to **move**, **edit**, **insert**, **save**, **quit**, or perform another command.
