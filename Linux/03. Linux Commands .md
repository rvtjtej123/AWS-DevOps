# 📁 Linux Directory & File Management Commands

---

## ✦ 1. Create a Directory

```bash
mkdir dirname
```

### Example:

```bash
mkdir project
```

➡️ Creates a directory named `project`.

> **`mkdir` = Make Directory**

---

## ✦ 2. Create Multiple Directories

```bash
mkdir dir1 dir2 dir3
```

### Example:

```bash
mkdir java maven docker
```

➡️ Creates all three directories at once.

---

## ✦ 3. Create Multiple Numbered Directories

```bash
mkdir dirname{1..50}
```

### Example:

```bash
mkdir project{1..5}
```

➡️ Creates:

```text
project1
project2
project3
project4
project5
```

You can also create up to 50 directories:

```bash
mkdir project{1..50}
```

---

# 🗑️ 4. Remove a Directory

There are **two main ways** to remove a directory.

---

## ➤ Remove an Empty Directory

```bash
rmdir dirname
```

### Example:

```bash
rmdir project
```

➡️ Removes the `project` directory **only if it is empty**.

### Example:

```text
project/
```

After running:

```bash
rmdir project
```

➡️ The directory is removed.

---

## ➤ Remove a Directory with Files

If the directory contains files or subdirectories:

```text
project/
├── file1.txt
├── file2.txt
└── documents/
    └── notes.txt
```

Use:

```bash
rm -r dirname
```

### Example:

```bash
rm -r project
```

➡️ Removes:

- `project`
- All files inside it
- All subdirectories
- All files inside the subdirectories

### `-r` means:

```text
Recursive
```

It goes through the directory and removes its contents recursively.

> ⚠️ **WARNING:** `rm -r` deletes the directory and its contents. Check the directory name before pressing Enter.

### Quick Difference

| Command | What it does |
|---|---|
| `rmdir dirname` | Removes an **empty directory only** |
| `rm -r dirname` | Removes a directory **with files and subdirectories** |

---

## ✦ 5. Enter a Directory

```bash
cd directoryname
```

### Example:

```bash
cd project
```

➡️ Moves you into the `project` directory.

---

## ✦ 6. Go One Step Back

```bash
cd ..
```

➡️ Moves to the parent directory.

### Example:

Current location:

```text
/home/ravi/project
```

Run:

```bash
cd ..
```

New location:

```text
/home/ravi
```

---

## ✦ 7. Go Two Steps Back

```bash
cd ../..
```

➡️ Moves two directories upward.

### Example:

Current location:

```text
/home/ravi/project/src
```

Run:

```bash
cd ../..
```

New location:

```text
/home/ravi
```

---

## ✦ 8. Copy a File

```bash
cp source_file destination
```

### Example:

```bash
cp notes.txt backup.txt
```

➡️ Creates a copy of `notes.txt` named `backup.txt`.

### Structure:

```text
cp SOURCE DESTINATION
```

---

## ✦ 9. Copy a File to a Directory

```bash
cp filename directoryname
```

### Example:

```bash
cp notes.txt backup/
```

➡️ Copies `notes.txt` into the `backup` directory.

---

## ✦ 10. Copy a Directory

To copy a directory and everything inside it:

```bash
cp -r source_directory destination
```

### Example:

```bash
cp -r project backup
```

➡️ Copies:

- The directory
- Files inside it
- Subdirectories
- Files inside subdirectories

### `-r` means:

```text
Recursive
```

---

## ✦ 11. Move a File or Directory

```bash
mv source destination
```

### Move a File:

```bash
mv notes.txt documents/
```

➡️ Moves `notes.txt` into the `documents` directory.

### Move a Directory:

```bash
mv project backup/
```

➡️ Moves the `project` directory into `backup`.

---

## ✦ 12. Rename a File

```bash
mv oldfilename newfilename
```

### Example:

```bash
mv file1.txt notes.txt
```

➡️ Renames:

```text
file1.txt
```

to:

```text
notes.txt
```

---

## ✦ 13. Rename a Directory

```bash
mv olddirname newdirname
```

### Example:

```bash
mv project devops-project
```

➡️ Renames:

```text
project
```

to:

```text
devops-project
```

---

## ✦ 14. View Hidden Files and Directories

```bash
ls -a
```

`-a` means **All**.

➡️ Shows hidden files and directories.

### Example:

```text
.
..
.git
.bashrc
file.txt
project
```

Files beginning with `.` are hidden.

Examples:

```text
.git
.bashrc
.profile
```

---

## ✦ 15. Detailed List of Files and Directories

```bash
ls -l
```

➡️ Displays detailed information such as:

- File type
- Permissions
- Owner
- Group
- File size
- Modification date
- File/Directory name

### Example:

```text
-rw-r--r--  file.txt
drwxr-xr-x  project
```

### First Character Meaning

| Character | Meaning |
|---|---|
| `-` | Regular File |
| `d` | Directory |
| `l` | Symbolic Link |

---

## ✦ 16. Reverse Order

```bash
ls -r
```

➡️ Displays the listing in reverse order.

---

## ✦ 17. Human-Readable File Size

```bash
ls -lh
```

### Breakdown:

```text
ls → List files
-l → Long/Detailed format
-h → Human-readable size
```

### Example:

Instead of:

```text
1048576
```

You may see:

```text
1.0M
```

---

## ✦ 18. Sort by Modification Time

```bash
ls -lt
```

### Breakdown:

```text
-l → Detailed format
-t → Sort by modification time
```

➡️ Recently modified files appear first.

---

## ✦ 19. Show Oldest Files First

```bash
ls -ltr
```

### Breakdown:

```text
-l → Long/Detailed format
-t → Sort by modification time
-r → Reverse order
```

➡️ Displays files from **oldest modified** to **most recently modified**.

---

## ✦ 20. Check the Current User

```bash
whoami
```

➡️ Displays the username of the current user.

### Example:

```text
ravi
```

---

## ✦ 21. Check Current Location

```bash
pwd
```

### `pwd` means:

```text
Print Working Directory
```

### Example Output:

```text
/home/ravi/project
```

➡️ Shows your current directory/location.

---

## ✦ 22. Exit from the Current Shell

```bash
exit
```

➡️ Exits the current shell or session.

For example, if you enter the root user:

```bash
sudo -i
```

You can return to your normal user using:

```bash
exit
```

---

## ✦ 23. Check System Boot Time

```bash
who -b
```

➡️ Shows when the system was last booted.

Example:

```text
system boot  2026-08-23 06:30
```

---

## ✦ 24. Complete System Information

```bash
uname -a
```

➡️ Displays detailed system information such as:

- Kernel name
- Hostname
- Kernel version
- Machine architecture
- Operating system information

---

## ✦ View Files Without Entering a Directory

To check the files inside a directory **without entering it**, use:

```bash
ls directoryname
```

### Example:

Suppose you have a directory called `project`:

```bash
ls project
```

➡️ This displays the files inside the `project` directory without using:

```bash
cd project
```

### Example Structure:

```text
/home/ravi
│
├── project
│   ├── file1.txt
│   ├── file2.txt
│   └── notes.txt
```

If your current location is:

```text
/home/ravi
```

Run:

```bash
ls project
```

### Output:

```text
file1.txt
file2.txt
notes.txt
```

---

### ➤ View Detailed Information

```bash
ls -l project
```

➡️ Displays detailed information about the files inside the `project` directory.

---

### ➤ View Hidden Files

```bash
ls -a project
```

➡️ Displays all files, including hidden files.

---

### ➤ View Detailed + Hidden Files

```bash
ls -la project
```

---

### Easy Way to Remember:

```text
ls
↓
Lists files in the Current Directory


ls directoryname
↓
Lists files inside Another Directory
without entering it
```
