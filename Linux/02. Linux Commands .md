# 🐧 Linux Commands

---

## ✦ `touch` Command

### ➤ To create a file:

```bash
touch filename
```

### Example:

```bash
touch file1.txt
```

➡️ This creates an **empty file** called `file1.txt`.

> **NOTE:**
> `touch` can also update the timestamp of an existing file.

<br>

---

## ✦ `ls` Command

### ➤ To view/list files:

```bash
ls
```

➡️ Displays the files and directories in the current location.

### Example:

```text
file1.txt  file2.txt  documents
```

### ➤ Detailed list:

```bash
ls -l
```

or

```bash
ll
```

➡️ Shows details such as:

- Permissions
- Owner
- File size
- Date and time
- File/Directory name

<br>

---

## ✦ Create Multiple Files

```bash
touch file1 file2 file3
```

### Example:

```bash
touch a.txt b.txt c.txt
```

➡️ Creates all three files at once.

<br>

---

## ✦ Create Multiple Numbered Files

```bash
touch filename{1..100}
```

### Example:

```bash
touch file{1..5}
```

➡️ This creates:

```text
file1
file2
file3
file4
file5
```

### Another Example:

```bash
touch file{1..100}
```

➡️ Creates files from:

```text
file1 → file100
```

<br>

---

## ✦ `rm` Command

### ➤ To remove/delete a file:

```bash
rm filename
```

### Example:

```bash
rm file1.txt
```

➡️ Deletes `file1.txt`.

> ⚠️ **NOTE:**
> Normally, `rm` does not move the file to a recycle bin.

<br>

---

## ✦ Remove Multiple Files

```bash
rm file1 file2 file3
```

### Example:

```bash
rm a.txt b.txt c.txt
```

➡️ Deletes all the specified files.

<br>

---

## ✦ Remove Multiple Numbered Files

```bash
rm file{1..100}
```

### Example:

```bash
rm file{1..10}
```

➡️ Removes:

```text
file1
file2
file3
...
file10
```

<br>

---

## ✦ `rm filename*`

### Example:

```bash
rm file*
```

➡️ Deletes files whose names start with `file`.

### Example:

```text
file1
file2
file.txt
filedata
```

All of these can match:

```bash
file*
```

> ⚠️ **WARNING:**
> Be very careful while using `*` because it can delete more files than you intended.

<br>

---

## ✦ `rm *`

```bash
rm *
```

➡️ Attempts to remove all non-hidden files in the current directory.

### Before using `rm *`, always check:

```bash
pwd
```

➡️ Shows your current directory.

```bash
ls
```

➡️ Shows the files in the current directory.

> ⚠️ **IMPORTANT:**
> Always verify the directory before using `rm *`.

<br>

---

# ✦ Clear Terminal Screen

### Command:

```bash
clear
```

### Shortcut:

```text
Ctrl + L
```

➡️ Both clear the visible terminal screen.

> **NOTE:**
> They do not delete your command history.

<br>

# 🐈 `cat` Command

`cat` means **concatenate**.

It is commonly used to:

- Create files
- Write data into files
- Display file contents
- Combine/display multiple files

---

## ✦ Create an Empty File

```bash
touch filename
```

### Example:

```bash
touch file1.txt
```

➡️ Creates an empty file.

---

## ✦ Create a File and Write Data Using `cat`

```bash
cat > filename
```

### Example:

```bash
cat > notes.txt
```

Then enter your data:

```text
Linux Commands
AWS DevOps
Maven
```

To save and exit:

```text
Ctrl + D
```

➡️ The file will now contain the entered data.

<br>

---

## ✦ `cat > filename`

```bash
cat > filename
```

➡️ Used to create a file or write data into a file.

### Example:

```bash
cat > file.txt
```

> ⚠️ **IMPORTANT:**
> If the file already contains data, `>` can overwrite the existing content.

### Example:

Before:

```text
Old Data
```

After running:

```bash
cat > file.txt
```

and entering new data:

```text
New Data
```

➡️ The old data can be replaced.

<br>

---

## ✦ `cat >> filename`

```bash
cat >> filename
```

➡️ Adds new data to an existing file **without deleting the existing content**.

### Example:

```bash
cat >> notes.txt
```

Enter:

```text
Docker
Kubernetes
```

Then press:

```text
Ctrl + D
```

### Difference:

```bash
cat > file.txt
```

➡️ Can overwrite existing data.

```bash
cat >> file.txt
```

➡️ Adds new data to the existing file.

<br>

---

# ✦ View Data in a File

```bash
cat filename
```

### Example:

```bash
cat notes.txt
```

### Output:

```text
Linux Commands
AWS DevOps
Maven
```

➡️ Displays the content of the file.

<br>

---

# ✦ Add Data to an Existing File

```bash
cat >> filename
```

### Example:

```bash
cat >> notes.txt
```

➡️ Adds new content to the existing file.

> **NOTE:**
> Use `>>` when you want to add data without removing the old data.

<br>

---

# ✦ Display Line Numbers

```bash
cat -n filename
```

### Example:

```bash
cat -n notes.txt
```

### Output:

```text
     1  Linux Commands
     2  AWS DevOps
     3  Maven
```

➡️ `-n` displays line numbers for **all lines**.

<br>

---

# ✦ Hide Blank Line Numbers

```bash
cat -b filename
```

### Example:

```bash
cat -b notes.txt
```

➡️ `-b` displays line numbers only for **non-empty lines**.

### Difference:

| Command | What it does |
|---|---|
| `cat -n filename` | Numbers all lines |
| `cat -b filename` | Numbers only non-empty lines |

<br>

---

# ✦ View Data from Multiple Files

```bash
cat filename1 filename2
```

### Example:

```bash
cat java.txt maven.txt
```

➡️ Displays the contents of both files one after another.

```text
Contents of java.txt

Contents of maven.txt
```

<br>

---

# ✦ `tac` Command

```bash
tac filename
```

➡️ Displays the contents of a file in **reverse line order**.

### Example:

```bash
tac notes.txt
```

If the file contains:

```text
Line 1
Line 2
Line 3
```

The output will be:

```text
Line 3
Line 2
Line 1
```

### Easy Way to Remember:

```text
cat → Normal order

tac → Reverse order
```

<br>

---

# ✦ Quick Summary

| Command | What it does |
|---|---|
| `touch file.txt` | Creates an empty file |
| `touch file{1..10}` | Creates multiple numbered files |
| `ls` | Lists files and directories |
| `ls -l` | Shows detailed file information |
| `rm file.txt` | Deletes a file |
| `rm file{1..10}` | Deletes multiple numbered files |
| `rm file*` | Deletes files matching the pattern |
| `clear` | Clears the terminal screen |
| `Ctrl + L` | Shortcut to clear the screen |
| `cat > file.txt` | Creates/writes to a file and can overwrite existing content |
| `cat >> file.txt` | Adds new data without deleting existing content |
| `cat file.txt` | Displays file contents |
| `cat -n file.txt` | Displays all lines with line numbers |
| `cat -b file.txt` | Numbers only non-empty lines |
| `cat file1 file2` | Displays multiple files |
| `tac file.txt` | Displays file contents in reverse line order |

---

# ✦ Important to Remember

```text
touch
   ↓
Creates an empty file


cat > filename
   ↓
Writes data, but can overwrite existing data


cat >> filename
   ↓
Adds new data without deleting existing data


cat filename
   ↓
Views/displays the file content
```

> ⚠️ **IMPORTANT:**
>
> - Be careful while using `rm`, especially `rm *`.
> - Be careful with `cat > filename` because it can overwrite existing data.
> - Use `cat >> filename` when you want to add data without removing the old content.
