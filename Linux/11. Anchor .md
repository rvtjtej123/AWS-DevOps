# Anchors

There are two types of anchors:

```text
^
```

➡️ Beginning of the line.

```text
$
```

➡️ End of the line.

---

## Display Lines Starting with a Word

```bash
grep ^wordname filename
```

➡️ Displays only the lines where `wordname` is at the **beginning of the line**.

Example:

```bash
grep ^Linux filename
```

If the file contains:

```text
Linux is an operating system
I like Linux
Linux commands are useful
My Linux notes
```

Output:

```text
Linux is an operating system
Linux commands are useful
```

---

## Display Lines Ending with a Word

```bash
grep wordname$ filename
```

➡️ Displays only the lines where `wordname` is at the **end of the line**.

Example:

```bash
grep Linux$ filename
```

If the file contains:

```text
I like Linux
Linux is useful
Learning Linux
Linux commands
```

Output:

```text
I like Linux
Learning Linux
```

# Display Only Files

First, use:

```bash
ll
```

The `ll` command displays both files and directories.

Example:

```text
-rw-r--r--  file1.txt
drwxr-xr-x  Documents
-rw-r--r--  file2.txt
drwxr-xr-x  Downloads
```

In the `ll` output:

```text
-
```

at the beginning means a **regular file**.

To display only files:

```bash
ll | grep ^-
```

### Breakdown

```bash
ll
```

➡️ Lists files and directories.

```bash
grep ^-
```

➡️ Displays only the lines starting with `-`.

So:

```bash
ll | grep ^-
```

➡️ **Displays only regular files.**

---

# Display Only Directories

First, use:

```bash
ll
```

The `ll` command displays both files and directories.

Example:

```text
-rw-r--r--  file1.txt
drwxr-xr-x  Documents
-rw-r--r--  file2.txt
drwxr-xr-x  Downloads
```

In the `ll` output:

```text
d
```

at the beginning means a **directory**.

To display only directories:

```bash
ll | grep ^d
```

### Breakdown

```bash
ll
```

➡️ Lists files and directories.

```bash
grep ^d
```

➡️ Displays only the lines starting with `d`.

So:

```bash
ll | grep ^d
```

➡️ **Displays only directories.**

---

# Count Files in a Directory

```bash
ll | grep ^- | wc -l
```

### Breakdown

```bash
ll
```

➡️ Lists files and directories.

```bash
grep ^-
```

➡️ Selects only regular files.

```bash
wc -l
```

➡️ Counts the number of lines.

So:

```bash
ll | grep ^- | wc -l
```

➡️ **Counts the number of regular files in the current directory.**

---

# Find a Directory by Name

```bash
ll | grep dirname
```

Example:

```bash
ll | grep Documents
```

➡️ Displays the entry containing `Documents`.

---


# Find a Directory by the Last Name / End of the Directory Name

Use:

```bash
ll | grep dirname$
```

Example:

```bash
ll | grep Documents$
```

Here:

```text
$
```

means **the end of the line**.

So:

```bash
ll | grep Documents$
```

➡️ Displays the directory or file entry that **ends with `Documents`**.

Example `ll` output:

```text
drwxr-xr-x  Documents
drwxr-xr-x  MyDocuments
drwxr-xr-x  DocumentsBackup
```

Command:

```bash
ll | grep Documents$
```

Output:

```text
drwxr-xr-x  Documents
```

Because only that line ends exactly with:

```text
Documents
```
