# `grep` — Global Regular Expression Print

`grep` is used to search for a **word, string, or pattern**.

It can search:

- Inside a file
- In multiple files
- In all files in the current directory
- Inside directories and subdirectories

---

## Find a Particular Word in a File

```bash
grep wordname filename
```

### Example:

```bash
grep hello file.txt
```

➡️ Searches for `hello` in `file.txt`.

It displays the lines containing the matching word.

You can also use:

```bash
cat filename | grep wordname
```

### Example:

```bash
cat file.txt | grep hello
```

---

## `-i` — Ignore Case

To search without worrying about uppercase or lowercase:

```bash
grep -i wordname filename
```

### Example:

```bash
grep -i hello file.txt
```

It can match:

```text
hello
Hello
HELLO
hElLo
```

➡️ `-i` means **ignore case**.

---

## `-r` — Recursive Search

To search for a word inside a directory and its subdirectories:

```bash
grep -r wordname dirname
```

### Example:

```bash
grep -r hello project
```

It searches:

- The specified directory
- Files inside the directory
- All subdirectories
- Files inside those subdirectories

➡️ `-r` means **recursive**.

---

## `-c` — Count Matching Lines

To count how many lines contain a particular word:

```bash
grep -c wordname filename
```

### Example:

```bash
grep -c hello file.txt
```

➡️ Displays the number of **matching lines**.

⚠️ `-c` counts matching **lines**, not the total number of times the word appears.

---

# `*` — All Files in the Current Directory

`*` means:

```text
All files in the current directory
```

For example:

```bash
grep hello *
```

➡️ Searches for `hello` in all files in the current directory.

You can also combine `*` with other options:

```bash
grep -i wordname *
```

➡️ Ignore case and search in all files.

```bash
grep -c wordname *
```

➡️ Count matching lines in all files.

```bash
grep -n wordname *
```

➡️ Show matching lines with line numbers from all files.

---

## `-l` — Display Filenames Containing the Matching Word

First, enter into the directory:

```bash
cd directoryname
```

Then run:

```bash
grep -l -i wordname *
```

### Example:

```bash
cd myfiles
```

Then:

```bash
grep -l -i hello *
```

Here:

```text
-l → Display only the filenames containing the matching word.

-i → Ignore uppercase and lowercase differences.

*  → Search in all files in the current directory.
```

➡️ This searches for `hello` in all files inside the `myfiles` directory and displays only the filenames that contain `hello`, regardless of uppercase or lowercase.

### Example Output:

```text
file1.txt
notes.txt
```

That means `file1.txt` and `notes.txt` contain the word `hello`.

---

## `-n` — Show Line Numbers

To find the line numbers where a word appears:

```bash
grep -n wordname filename
```

### Example:

```bash
grep -n hello file.txt
```

Suppose the file contains:

```text
Hello Ravi
Linux
Hello World
Ubuntu
```

Output:

```text
1:Hello Ravi
3:Hello World
```

➡️ The number before `:` is the **line number**.

---

## `-v` — Invert Search

To display all lines **except** the lines containing a particular word:

```bash
grep -v wordname filename
```

### Example:

```bash
grep -v hello file.txt
```

Suppose the file contains:

```text
Hello Ravi
Linux
Hello World
Ubuntu
```

Output:

```text
Linux
Ubuntu
```

➡️ `-v` means **invert search**.

It skips the matching lines and displays everything else.

---

# Quick Summary

```text
grep wordname filename
→ Search for a word or pattern in a specific file.

grep wordname *
→ Search for a word or pattern in all files in the current directory.

grep -i wordname filename
→ Search while ignoring uppercase and lowercase differences.

grep -i wordname *
→ Ignore case and search in all files in the current directory.

grep -r wordname dirname
→ Recursively search inside a directory and all its subdirectories.

grep -c wordname filename
→ Count the number of matching lines in a file.

grep -c wordname *
→ Count matching lines in all files in the current directory.

cd directoryname
grep -l -i wordname *
→ Enter a directory, search all files, ignore case,
  and display only filenames containing the matching word.

grep -n wordname filename
→ Display matching lines with their line numbers.

grep -n wordname *
→ Display matching lines with line numbers from all files.

grep -v wordname filename
→ Display all lines except the lines containing the specified word.
```
