# Shell Commands

## 1. To Know the Default Shell

```bash
echo $SHELL
```

This shows your **default login shell**.

### Example:

```bash
echo $SHELL
```

Output:

```text
/bin/bash
```

This means your default shell is **Bash**.

> `$SHELL` usually shows your configured default/login shell. It may not always show the shell you are currently using.

---

## 2. To Know the Current Shell

```bash
echo $0
```

This shows the name of the **current shell**.

### Example:

```bash
echo $0
```

Output:

```text
bash
```

This means you are currently using **Bash**.

---

## 3. Switching to Another Shell

For example, to switch to **C Shell**:

```bash
csh
```

If you are currently using:

```text
bash
```

and you run:

```bash
csh
```

You enter the C Shell:

```text
bash
  ↓
csh
```

You can also start other installed shells:

```bash
bash
```

```bash
zsh
```

---

## 4. Switch Back to the Previous Shell

```bash
exit
```

Example:

```text
bash
  ↓
csh
  ↓ exit
bash
```

When you run:

```bash
exit
```

you close the current shell session and return to the **previous shell**.

### Simple Understanding

Starting another shell:

```bash
csh
```

creates a new shell session inside your current shell.

Then:

```bash
exit
```

closes that current shell session and takes you back to the previous shell.

# Root Directory vs Root User

## 1. `/` — Root Directory

```text
/
```

`/` means the **root directory**.

It is the **top-level directory** in Linux.

All other directories and files come under `/`.

### Example:

```text
/
├── home
├── bin
├── etc
├── var
└── root
```

So `/` is the starting point of the Linux file system.

---

## 2. `/root` — Root User's Home Directory

```text
/root
```

`/root` is **not the same as `/`**.

`/root` is the **home directory of the root user**.

Just like a normal user has a home directory:

```text
/home/username
```

the root user has:

```text
/root
```

---

## 3. Root User Can Create Files in Many Locations

The **root user** is the administrator of the Linux system and normally has permission to create, modify, or delete files in protected system locations.

For example:

```text
/
├── home
├── etc
├── var
└── root
```

The root user can work in these system directories if required.

But don't confuse:

```text
/       → Root directory (top of the file system)

/root   → Home directory of the root user
```

### Simple Example

```text
Normal user:

Username: ravi
Home directory: /home/ravi


Root user:

Username: root
Home directory: /root
```

## Summary

```text
/       → Root directory
          Top-level directory of Linux.

/root   → Root user's home directory.

$SHELL  → Shows the default/login shell.

$0      → Shows the current shell.

csh     → Starts the C Shell.

exit    → Closes the current shell and returns to the previous shell.
```
