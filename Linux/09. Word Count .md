# `wc` — Word Count Command

`wc` stands for **Word Count**.

It is used to count:

- Lines
- Words
- Characters
- Bytes

## Basic Syntax

```bash
wc [option] filename
```

## `wc filename`

To see the default counts of a file:

```bash
wc filename
```

### Example:

```bash
wc file.txt
```

Output:

```text
10  50  300  file.txt
```

By default, `wc` shows:

```text
Lines  Words  Bytes  Filename
```

So:

- `10` → Number of lines
- `50` → Number of words
- `300` → Number of bytes
- `file.txt` → Filename

---

## Count Words

To count how many words are in a file:

```bash
wc -w filename
```

### Example:

```bash
wc -w file.txt
```

➡️ Displays the total number of **words**.

---

## Count Lines

To count how many lines are in a file:

```bash
wc -l filename
```

### Example:

```bash
wc -l file.txt
```

➡️ Displays the total number of **lines**.

---

## Count Characters

To count how many characters are in a file:

```bash
wc -m filename
```

### Example:

```bash
wc -m file.txt
```

➡️ Displays the total number of **characters**.

---

## Count Bytes

To find the file size/content size in bytes:

```bash
wc -c filename
```

### Example:

```bash
wc -c file.txt
```

➡️ Displays the total number of **bytes**.

---

# Quick Summary

```text
wc filename      → Lines, words, bytes, and filename

wc -w filename   → Count words

wc -l filename   → Count lines

wc -m filename   → Count characters

wc -c filename   → Count bytes
```

## Options Meaning

```text
-w → Words

-l → Lines

-m → Characters

-c → Bytes
```
