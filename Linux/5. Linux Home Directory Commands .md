# 🏠 Linux Home Directory Commands

---

## ✦ 1. Go to the Home Directory

To go directly to your **Home Directory**, use:

```bash
cd
```

You can also use:

```bash
cd ~
```

➡️ `~` represents the **current user's Home Directory**.

### Example:

If the username is `ravi`:

```text
/home/ravi
```

```text
~
↓
/home/ravi
```

---

## ✦ 2. Copy Multiple Directories to a Single Directory

To copy multiple directories into another directory, use:

```bash
cp -r directory1 directory2 destination_directory
```

### Example:

```bash
cp -r dir1 dir2 backup/
```

➡️ Copies both `dir1` and `dir2` into the `backup` directory.

### `-r` means:

```text
Recursive
```

It copies the directory along with:

- Files inside it
- Subdirectories
- Files inside the subdirectories

---

## ✦ 3. Move a File from the Current Directory to the Home Directory

Use:

```bash
mv filename ~
```

### Example:

```bash
mv notes.txt ~
```

➡️ Moves `notes.txt` from the **current directory** to your **Home Directory**.

You can also use:

```bash
mv notes.txt /home/ravi/
```

---

## ✦ 4. View Home Directory Contents Without Going There

If you are currently inside another directory, you can check the files and directories inside your **Home Directory** using:

```bash
ls ~
```

➡️ `~` represents the current user's **Home Directory**.

### Example:

Suppose your current location is:

```text
/home/ravi/project
```

Run:

```bash
ls ~
```

### Example Output:

```text
Desktop
Documents
Downloads
Pictures
project
```

➡️ This displays the contents of your **Home Directory** without leaving your current directory.
