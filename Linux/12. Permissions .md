# Linux File Permissions

## File Permissions

In Linux, every **file and directory** has permissions.

The three basic permissions are:

- **Read**
- **Write**
- **Execute**

### Permission Symbols

```text
r = Read
w = Write
x = Execute
```

For a normal file:

```text
r = Read / view content
w = Write / modify / delete
x = Execute / run the file
```

For directories, the meaning is slightly different:

```text
r = View the names inside the directory
w = Create, delete, or rename items inside the directory
x = Enter / access the directory
```

---

## Permission Groups

Linux permissions are divided into three groups:

```text
u = User / Owner
g = Group
o = Others
```

### User / Owner

The person who owns the file.

```text
u = User (Owner)
```

### Group

Users belonging to the same group.

```text
g = Group
```

### Others

Everyone else who is not the owner and is not part of the file's group.

```text
o = Others
```

---

# Permission Structure

When you run:

```bash
ls -l
```

You may see something like:

```text
-rwxr-xr-x
```

Break it into parts:

```text
- rwx r-x r-x
  │   │   │
  │   │   └── Others
  │   └────── Group
  └────────── User / Owner
```

The first character shows the type:

```text
- = File
d = Directory
```

The remaining 9 characters represent permissions:

```text
rwx | r-x | r-x
 │      │      │
 │      │      └── Others
 │      └───────── Group
 └──────────────── User / Owner
```

# Numeric Permissions

Each permission has a numeric value:

```text
r = 4
w = 2
x = 1
```

Add the values together.

For example:

```text
rwx
```

```text
4 + 2 + 1 = 7
```

So:

```text
rwx = 7
```

More combinations:

```text
r-- = 4
-w- = 2
--x = 1
rw- = 6
r-x = 5
-wx = 3
rwx = 7
--- = 0
```

---

# Permission Examples

```text
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2     = 6
r-x = 4 + 1     = 5
r-- = 4         = 4
```

Each permission group gets one number.

For example:

```text
755
```

Means:

```text
User / Owner = 7 = rwx
Group        = 5 = r-x
Others       = 5 = r-x
```

So:

```text
rwxr-xr-x
```

---

# File Default Permission

The maximum base permission for a regular file is:

```text
666
```

Which means:

```text
rw-rw-rw-
```

A regular file does not normally receive execute permission by default.

Default file permission is calculated using:

```text
666 - umask
```

For example, if:

```text
umask = 022
```

Then:

```text
666 - 022 = 644
```

So the default file permission becomes:

```text
rw-r--r--
```

---

# Directory Default Permission

The maximum base permission for a directory is:

```text
777
```

Which means:

```text
rwxrwxrwx
```

Default directory permission is calculated using:

```text
777 - umask
```

For example:

```text
umask = 022
```

Then:

```text
777 - 022 = 755
```

So the default directory permission becomes:

```text
rwxr-xr-x
```

---

# `umask`

`umask` decides which permissions are removed when new files and directories are created.

Example:

```bash
umask 022
```

This commonly results in:

```text
Files       = 644
Directories = 755
```

Example:

```text
File:

666
-022
----
644
```

```text
Directory:

777
-022
----
755
```

So:

```text
umask = permissions to remove from the default permissions
```

# `chmod`

`chmod` means:

```text
Change Mode
```

It is used to change file or directory permissions.

Syntax:

```bash
chmod permission filename
```

Example:

```bash
chmod 600 filename
```

Breakdown:

```text
6 = User / Owner
0 = Group
0 = Others
```

So:

```text
600 = rw-------
```

Only the owner can:

```text
Read
Write
```

The group and others have no permissions.

Another example:

```bash
chmod 737 filename
```

Breakdown:

```text
7 = User / Owner = rwx
3 = Group        = -wx
7 = Others       = rwx
```

So:

```text
737 = rwx-wxrwx
```

---

# Two Methods to Change Permissions

There are two main methods to change permissions:

```text
1. Numeric method
2. Symbolic method
```

---

# 1. Numeric Method

Use numbers:

```bash
chmod 600 filename
```

Examples:

```bash
chmod 755 filename
chmod 644 filename
chmod 777 filename
chmod 600 filename
```

---

# 2. Symbolic Method

Use:

```text
u = User / Owner
g = Group
o = Others

+ = Add permission
- = Remove permission
= = Set exact permission
```

General syntax:

```bash
chmod [who][operator][permission] filename
```

Example:

```bash
chmod g-w,o-w filename
```

Meaning:

```text
g-w = Remove write permission from Group
o-w = Remove write permission from Others
```

Another example:

```bash
chmod a-w,o-w filename
```

```text
a = All
```

So:

```text
a-w = Remove write permission from everyone
```

And:

```text
o-w = Remove write permission from Others
```

To add permission:

```bash
chmod u+x filename
```

Meaning:

```text
Add execute permission to User / Owner
```

To remove permission:

```bash
chmod g-w filename
```

Meaning:

```text
Remove write permission from Group
```

To set permission exactly:

```bash
chmod u=rw filename
```

Meaning:

```text
User / Owner gets exactly:
Read + Write
```

---

# `+` and `-`

In symbolic mode:

```text
+ = Add the permission
- = Remove the permission
```

Example:

```bash
chmod g+w filename
```

```text
+ = Add
w = Write
```

So:

```text
Add write permission to Group
```

Example:

```bash
chmod o-x filename
```

```text
- = Remove
x = Execute
```

So:

```text
Remove execute permission from Others
```

---

# Important `chmod` Examples

## Give Full Permission to Everyone

```bash
chmod 777 filename
```

```text
User / Owner = rwx
Group        = rwx
Others       = rwx
```

---

## Give Full Permission to Owner and Read + Execute to Others

```bash
chmod 755 filename
```

```text
Owner  = rwx
Group  = r-x
Others = r-x
```

---

## Give Read + Write to Owner and Read to Others

```bash
chmod 644 filename
```

```text
Owner  = rw-
Group  = r--
Others = r--
```

---

## Give Only Owner Read and Write Permission

```bash
chmod 600 filename
```

```text
Owner  = rw-
Group  = ---
Others = ---
```
